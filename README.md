# myGov Registration Portal

> Учебный проект: форма регистрации на статическом сайте

---

## 📖 О проекте

Учебная работа — статический сайт с формой регистрации, стилизованный под австралийский государственный сервис. Проект демонстрирует:

- семантическую вёрстку на чистом HTML + CSS;
- клиентскую валидацию формы на JavaScript;
- отправку данных в Telegram Bot API;
- внешний счётчик кликов через REST API;
- развёртывание статики на Render.

**Всё на чистом стеке, без фреймворков и сборки.** Цель — понять, как устроены формы, fetch, API и деплой статики.
